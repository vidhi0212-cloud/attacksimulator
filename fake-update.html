Information Security Guidelines & Acceptable Use Policy
📅 Last updated: 14 March 2025 📝 Version 4.2 👤 IT Security Team 🔄 Review due: Q3 2025

⚠ Notice: This document has been significantly updated. All employees are required to review the updated sections highlighted in blue before end of this week.

1. Purpose & Scope

This document establishes the information security policies and acceptable use guidelines for all employees, contractors, and third-party users who access Acme Corp's information systems, networks, and data.

These policies apply to all digital assets including workstations, mobile devices, cloud services, email systems, and any equipment connected to the corporate network.

2. Password & Access Management

All employees must adhere to the following password standards to protect corporate systems from unauthorised access:

  • Minimum 14 characters, combining uppercase, lowercase, numbers, and symbols
  • Passwords must be changed every 90 days — the system will prompt you automatically
  • Multi-factor authentication (MFA) is mandatory for all VPN and cloud service access
  • Never share credentials with colleagues, even temporarily
  • Use the approved password manager (LastPass Enterprise) for all accounts

3. Email Security

Email is the most common vector for cyberattacks including phishing, malware delivery, and business email compromise (BEC). All employees must follow these guidelines:

  • Never click links or open attachments from unknown or suspicious senders
  • Verify unexpected financial requests by phone — never via email alone
  • Report suspicious emails to security@acme.com before deleting
  • Do not use personal email accounts for any business communication

ℹ Note: IT will never ask for your password via email. If you receive such a request, it is a phishing attempt. Report it immediately.

4. Device & Endpoint Security

All corporate devices must have the Acme Endpoint Protection agent installed and running. Employees must not disable, bypass, or modify security software. Devices used for work must have:

  • Full-disk encryption (BitLocker on Windows, FileVault on macOS)
  • Automatic screen lock after 5 minutes of inactivity
  • Operating system and application updates applied within 72 hours of release
  • No unauthorized software installed without IT approval

5. Incident Reporting

All suspected security incidents — including lost devices, phishing emails, unusual account activity, or accidental data disclosure — must be reported within 1 hour to the Security Operations Centre:

  • 📧 security@acme.com
  • 📞 Internal extension: 4422 (24/7 SOC hotline)
  • 🌐 Incident portal: intranet.acme.com/security/report
